# D(사전학습) 결과 — aqsoldb · scaffold_random (주 분석)

- 판정 규칙: `docs/design/05_PRETRAIN_SPEC.md` §4 (결과 전 고정, 커밋 3f50a0f). 주 지표 **RMSE** (작을수록 좋음)
- 탐색 횟수: 라벨 ≤1,000개는 20회, ≥3,000개는 10회 체크포인트. 모든 모델이 같은 체크포인트 (05 §2.2 T1)

- 미세조정: CPU 결정론, 프로세스 1스레드. 사전학습 가중치 SHA-256은 각 행의 config_hash에 들어 있다

## 3. 가설 판정 (05 §4 규칙 그대로)

### D  마스킹 사전학습

- **H1** (D − C_fixed 이득이 예산이 늘수록 줄어드는가, 기술만): 이득 중앙값 100 -0.071 → 300 -0.155 → 1000 -0.120 → 3000 -0.108 → full -0.064 — 단조 감소 아님
- **H2** (교차점): D 우세로 유의한 가장 큰 예산 없음, B 우세로 유의한 가장 작은 예산 100
- **H4** (구조 탐색 효과와 함께 보기): 예산별 이득 중앙값 D − C_fixed / D − C v2 = 100 -0.071 / +0.012, 300 -0.155 / -0.183, 1000 -0.120 / -0.122, 3000 -0.108 / -0.080, full -0.064 / -0.057

### D  대조학습 사전학습

- **H1** (D − C_fixed 이득이 예산이 늘수록 줄어드는가, 기술만): 이득 중앙값 100 -0.064 → 300 -0.067 → 1000 -0.109 → 3000 -0.064 → full -0.032 — 단조 감소 아님
- **H2** (교차점): D 우세로 유의한 가장 큰 예산 없음, B 우세로 유의한 가장 작은 예산 100
- **H4** (구조 탐색 효과와 함께 보기): 예산별 이득 중앙값 D − C_fixed / D − C v2 = 100 -0.064 / -0.018, 300 -0.067 / -0.091, 1000 -0.109 / -0.096, 3000 -0.064 / -0.043, full -0.032 / -0.030
