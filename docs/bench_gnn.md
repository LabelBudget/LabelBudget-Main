조기 종료로 학습 길이가 28~54 에폭에서 갈리므로, 비용 비교는 fit_sec가 아니라 sec_per_epoch로 한다.

### 재현성 — 위 표의 두 장치 모두 같은 시드에서 결과가 달라졌다

`repro_max_abs_diff`가 full에서 1.6~1.9 logS이고 조기 종료 에폭이 28↔52, 30↔54로 갈린다.
`scatter_sum`(`index_add_`)의 멀티스레드 누적 순서가 매번 달라 생기는 부동소수점 차이를 조기 종료가 키운 것이다.
라벨 1,000개, 8에폭 고정으로 따로 측정한 결과:

| 설정 | 같은 시드 2회 예측 최대 차이 | 시간 |
|---|---:|---:|
| CPU 8스레드 | 5.2e-02 | 8.0s |
| CPU 1스레드 | 0 | 9.1s |
| CPU 8스레드 + `torch.use_deterministic_algorithms(True)` | 0 | 8.4s |
| MPS | 1.1e-01 | 4.4s |
| MPS + 결정론 모드 | 실행 불가 (`index_put_with_accumulate_mps`에 결정론 구현 없음) | — |

full(3에폭)에서도 CPU 결정론 모드는 차이 0, 시간 16.4s 대 16.2s로 속도 손해가 없었다.
