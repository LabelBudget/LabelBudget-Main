# LabelBudget — 연구 기획서

> 분자 물성 예측에서 자기지도 사전학습의 이득은 라벨 몇 개까지 유효한가?

- 최종 갱신: 2026-10-22
- 성격: 포트폴리오용 연구 프로젝트 (제품 아님)
- 예상 기간: 12주
- 산출물: 연구 리포트 + 재현 가능한 코드 + (부록) 데모 앱

---

## 1. 왜 이 주제인가

문헌의 결론이 서로 충돌하고 있어, **아직 닫히지 않은 질문**이다.

| 출처 | 결론 |
|---|---|
| Nature Communications (2023) | RDKit 2D 서술자 + 랜덤 포레스트가 사전학습 모델(MolBERT, GROVER)과 GNN(GCN, GIN)을 **대부분의 데이터셋에서 이겼다**. 단 GROVER는 **저데이터에서만 예외적으로** 좋았다. 1,000개 미만에서 학습 기반 모델은 고전했고, 시드 30개에 따라 **모델 순위가 바뀌었다** |
| Sun et al., NeurIPS (2022) | 자기지도 GNN 사전학습은 **"많은 설정에서 통계적으로 유의한 우위가 없다"**. 지도 사전학습은 효과가 있으나 입력 피처가 풍부해지면 이득이 줄고, **하이퍼파라미터가 사전학습 과제보다 성능에 더 큰 영향**을 줬다 |
| Systematic Survey (2026) | 평가 프로토콜을 바꾸자 ADME 6개 엔드포인트에서 **4개의 서로 다른 모델이 각각 1위**를 차지. "보편적으로 최적인 패러다임은 없다" |

세 문헌이 공통으로 가리키는 지점은 하나다. **문제는 모델이 아니라 평가와 데이터 조건이다.**

따라서 "사전학습이 좋다/나쁘다"가 아니라 **"언제까지 좋은가"** 를 측정하는 것이 유효한 연구 질문이 된다.

## 2. 연구 질문과 가설

### 주 질문
> 자기지도 사전학습의 이득은 라벨 수가 몇 개 미만일 때만 통계적으로 유의하며, 그 경계는 과제·분할 전략에 따라 어떻게 이동하는가?

### 가설

| ID | 가설 |
|---|---|
| **H1** | 사전학습 이득은 라벨 수에 **단조 감소**한다 |
| **H2** | 서술자 기반 GBM이 사전학습 GNN을 역전하는 **교차점이 존재**한다 |
| **H3** | 그 교차점은 random split보다 **scaffold split에서 더 오른쪽으로 이동**한다 (어려운 분할에서 사전학습이 더 오래 유효) |
| **H4** | 동일 하이퍼파라미터 탐색 예산을 강제하면 사전학습 이득이 **문헌 보고보다 작게** 나온다 (NeurIPS 2022의 지적 검증) |

가설이 **기각되어도 유효한 결과**다. H1~H4 중 어느 쪽이든 문헌과의 일치/불일치를 보고하면 재현 연구로 성립한다.

## 3. 실험 설계

### 3.1 비교군 4종

| ID | 모델 | 역할 |
|---|---|---|
| **A** | ECFP4(2048bit) + LightGBM | 바닥 기준. 사전학습 개념이 없는 쪽 |
| **B** | RDKit 2D 서술자 + LightGBM | 문헌상 가장 강한 싸구려 베이스라인 |
| **C** | GNN (D-MPNN/GIN) 처음부터 학습 | 사전학습 효과의 대조군 |
| **D** | GNN + 자기지도 사전학습 → 미세조정 | 실험군 |

C와 D는 **백본 구조가 동일해야 한다.** 다르면 사전학습 효과와 구조 효과가 뒤섞인다.

### 3.2 핵심 축: 라벨 예산 스윕

```
회귀 (용해도) : 100 → 300 → 1,000 → 3,000 → 전체
분류 (독성)   : 300 → 1,000 → 3,000 → 전체     ← 100은 제외
```

- 테스트셋은 **고정**하고 학습셋만 줄인다
- 분류는 양성 비율을 유지한 **층화 서브샘플링**
- 서브샘플링 시드와 분할 시드를 **분리**한다

> **분류에서 100을 제외하는 이유:** Tox21 최적 과제(SR-ARE)도 양성률 16.15%여서
> 라벨 100개면 양성이 16개뿐이다. 더 불균형한 과제는 4개까지 떨어진다.
> 양성 20개 미만에서는 AUPRC가 사실상 무작위 수준으로 요동친다.
> 구현 스펙 §1.4 참조.

### 3.3 분할 전략

| 전략 | 용도 | 주의 |
|---|---|---|
| `random` | 낙관적 상한 | 이 숫자만 보고하면 안 됨 |
| `scaffold` | Bemis-Murcko 골격 | **결정론적 → 시드 분산이 0** |
| `scaffold_random` | 골격 그룹을 시드로 섞음 | **시드 분산 측정은 반드시 이걸로** |
| `time` | 등록 연도 기준 | ESOL/Tox21/AqSolDB에 날짜 없음. ChEMBL 추출분에만 적용 |

> `scaffold`로 시드 10개를 돌려 "분산을 측정했다"고 쓰는 것은 흔한 오류다.
> 결정론적 분할은 매번 같은 결과를 낸다.

### 3.4 공정성 규칙 (반드시 지킬 것)

1. **모든 모델에 동일한 하이퍼파라미터 탐색 예산**(시행 횟수)을 부여하고 그 숫자를 리포트에 명시
2. 시드 **10개** 이상, 평균 ± 표준편차 병기. 단일 숫자 금지
3. 모델 간 비교는 **Wilcoxon signed-rank test** (paired, 시드 기준)
4. 하이퍼파라미터 선택은 **valid**에서만. test는 최종 1회만 조회
5. 모든 분할 후 **누수 점검** 통과 필수

1번과 4번이 특히 중요하다. NeurIPS 2022가 지적한 "하이퍼파라미터가 사전학습 과제보다 영향이 크다"는 문제를 통제하지 않으면 결과 전체가 무의미해진다.

### 3.5 사전학습 설정

| 항목 | 값 |
|---|---|
| 데이터 | ZINC 250k 또는 ChEMBL subset (**라벨 없음**) |
| 과제 1 | Masked atom prediction |
| 과제 2 | Contrastive (부분구조 제거 / 원자 마스킹 증강) |
| 백본 | GIN 또는 D-MPNN (비교군 C와 **동일 구조**) |
| 규모 상한 | 단일 GPU 1일 이내. **100만 개 이상으로 키우지 말 것** |

## 4. 데이터셋 (전부 실측 검증 완료)

| 데이터 | 과제 | 실측 규모 | 라벨 컬럼 | 확보 |
|---|---|---|---|---|
| **AqSolDB** | 회귀 logS | 9,982 × 26 | `Solubility` | ✅ 파일 확보 + 감사 완료 |
| ESOL (Delaney) | 회귀 logS | 1,128 × 10 | `measured log solubility in mols per litre` | ✅ 자동 |
| **Tox21** | 분류 12과제 | 7,831 × 15 | `SR-ARE` 권장 | ✅ 자동 |
| Lipophilicity | 회귀 logD | 4,200 × 4 | `exp` | ✅ 자동 (보조) |

### 주 실험 조합

| 역할 | 데이터 | 이유 |
|---|---|---|
| 회귀 주 데이터 | **AqSolDB** | 9,982건으로 라벨 스윕 범위가 넓다. logS 범위 15 단위 |
| 회귀 대조 | ESOL | 1,128건. 저데이터 구간만으로 구성된 데이터에서의 거동 비교 |
| 분류 주 데이터 | **Tox21 / SR-ARE** | 유효 5,832건, 양성 942건(16.15%)으로 12과제 중 가장 균형적 |

Lipophilicity는 "과제에 따라 교차점이 이동하는가"를 볼 여유가 생기면 추가한다.

### ⚠️ AqSolDB 감사에서 드러난 설계 변경

실측 감사 결과, 표준 전처리인 **염 제거(LargestFragmentChooser)가 용해도 라벨을 파괴**한다는 것을 확인했다.

| 정책 | 통과 | 고유 분자 | 인공 중복 그룹 | spread>1.0 |
|---|---:|---:|---:|---:|
| 염 제거 | 9,611 | 9,276 | **191** | 102 |
| **다단편 거부** | 8,746 | 8,740 | **6** | **1** |

짝이온이 용해도를 결정하므로, 염을 벗기면 탄산나트륨(logS +0.58)과 탄산납(logS -5.55)이 같은 분자가 된다. **용해도 과제에서는 염을 제거하지 않는다.** 상세 근거는 `03_AQSOLDB_AUDIT.md`.

## 5. 최종 산출물

### 5.1 핵심 그래프 (이 프로젝트의 결론)

```
성능
 │     B(서술자+GBM) ─────────────────
 │    ╱
 │   ╱  D(사전학습 GNN)
 │  ╱ ╲____ C(처음부터 학습)
 │ ╱
 └──────────────────────────────► 라벨 수
   100    300    1K    3K    전체
                  ↑
         교차점 = 사전학습이 의미를 잃는 경계
```

분할 전략별로 이 그래프를 각각 그려, 교차점이 이동하는지 본다(H3).

### 5.2 결론 문장 형식

> 사전학습 이득은 라벨 N개 미만에서만 통계적으로 유의하며(Wilcoxon p<0.05), 그 이상에서는 서술자 기반 GBM이 더 낫다. 이 경계는 random split에서 N₁, scaffold split에서 N₂로 이동한다.

### 5.3 측정 노이즈 하한 (반드시 명기)

AqSolDB의 `SD` 컬럼(출처 간 측정 표준편차)으로 실측했다.

> 복수 출처에서 측정된 2,236개 분자의 출처 간 표준편차는 평균 **0.301 logS**다.
> 따라서 이 데이터에서 RMSE 0.3 미만은 측정 노이즈 구간이며, 그 이하의 개선은 실질적 의미가 없다.

이 한 문장이 **"자기 결과의 천장을 아는 사람"** 이라는 신호를 준다.

|---|---|---|

## 7. 구현력 증명 장치 2개

연구 설계만으로는 "구현도 되나?"라는 의심이 남는다. 두 개만 넣으면 해결된다.

### (1) 메시지 패싱 직접 구현
PyG의 `MessagePassing`을 상속하지 말고, `scatter` 연산으로 D-MPNN을 한 번 **처음부터** 구현한다. 그 다음 PyG 버전과 수치가 일치하는지 테스트로 검증한다.

```
tests/test_mpnn_equivalence.py
  → 직접 구현 vs PyG 구현 출력 차이 < 1e-5
```

이 테스트 파일 하나가 "라이브러리 사용자"와 "작동 원리를 아는 사람"을 가른다.

### (2) 공식 구현 재현 검증
Chemprop 논문의 보고 수치를 같은 분할·같은 지표로 재현하고, 차이가 나면 원인을 기록한다. *"재현했고, 0.0X 차이는 분할 시드 때문"* 까지 쓰면 신뢰도가 크게 올라간다.

## 8. 저비용 추가 실험 — 라벨 신뢰도 층화 평가

AqSolDB는 자체 신뢰도 등급을 매겨 두었다.

| Group | 건수 | 의미 |
|---|---:|---|
| G1 | 7,746 | 단일 출처 (`Ocurrences=1`, `SD=0`) — **교차 검증되지 않은 라벨** |
| G2 | 235 | |
| G3 | 1,182 | |
| G4 | 183 | |
| G5 | 636 | |

### 제안

> 신뢰도 등급별로 테스트 성능을 나눠 보고한다.

- 가설: 라벨 신뢰도가 높은 구간(복수 출처 합의)에서 모델 성능이 더 좋게 나온다
- 그렇다면 전체 RMSE는 **라벨 품질과 모델 성능이 섞인 값**이라는 뜻이다
- 공수: 거의 없다. 이미 있는 컬럼으로 테스트셋을 쪼개 집계만 하면 된다

비용 대비 신호가 가장 좋은 추가 실험이다. **라벨 예산 축(주 실험)을 흐리지 않으면서** 데이터 품질 감각을 보여준다.

## 9. 피해야 할 것

| 금지 | 이유 |
|---|---|
| 사전학습 데이터를 100만 개 이상으로 키우기 | 시간만 녹고 결론은 안 바뀜 |
| GNN이 이기는 그림을 만들려고 베이스라인 튜닝을 덜 하기 | 바로 들킴. 프로젝트 신뢰도 전부를 잃음 |
| 최신 아키텍처(Transformer 계열) 추가 투입 | 축이 흐려짐. **라벨 수 축 하나만 깊게** |
| random split 결과만 보고 | 아는 사람에게 감점 |
| AUROC 단독 보고 (Tox21) | 불균형이 심해 낙관적으로 보임 |
| Pearson R을 제곱해 R²로 쓰기 | 서로 다른 값이다 |
| 용해도 과제에서 염 제거 | 라벨 파괴. `03` §4 참조 |
| 결과가 음성이라 숨기기 | 문헌과 일치하는 재현 결과도 결과다 |
