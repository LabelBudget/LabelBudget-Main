### 결정 P2. 평가 분자와 겹치는 사전학습 분자

| 후보 | 장점 | 단점 |
|---|---|---|
| **① 평가 데이터셋 전체(AqSolDB·Tox21·ESOL)와 골격 일치하는 분자를 제거 (권장)** | 어떤 분할·시드에서도 test 분자를 사전학습에서 보지 않음. 입체만 다른 분자까지 막음 | 약 150개(0.06%) 손실 |
| ② InChIKey 완전 일치만 제거 | 손실 30개 | 입체이성질체로 우회 누수 가능 |
| ③ 제거하지 않음 | 가장 단순 | 라벨은 없어도 test 구조를 미리 본 전이적(transductive) 누수. 리뷰에서 바로 지적됨 |

권장 이유: 분할이 시드마다 바뀌어 "test만 제거"는 불가능하다. 전체 제거 비용이 무시할 만하다.

### 결정 P3. 사전학습 과제 2종의 구체적 형태

| 과제 | 권장 형태 | 대안 |
|---|---|---|
| 마스킹 | 원자 15%를 골라 원자 피처를 0으로 바꾸고 원자 종류(38종: `ATOMIC_NUMS` + 미지)를 맞힌다 (Hu et al. 2020 AttrMasking) | 원자 종류 외 전하·수소 수까지 다중 출력 |
| 대조학습 | GraphCL 계열: 한 분자에서 증강 뷰 2개(원자 피처 마스킹 + 원자 삭제), 그래프 표현 → 2층 projection → NT-Xent | 원자 피처 마스킹만 (구현 쉬움, 그러나 마스킹 과제와 너무 비슷해짐) |

- D-MPNN은 첫 메시지가 `W_i · [x_v ‖ e_vw]`라 원자 피처가 결합 메시지에도 들어간다. `g.V`의 행을 바꾸면 `W_i`와 `W_o` 양쪽에 반영되므로 마스크가 새지 않는다 (테스트로 확인할 것)
- 원자 삭제는 MolGraph에서 원자와 그 결합(양방향)을 지우고 `rev` 인덱스를 다시 만든다
- **GraphCL 공개 코드에서 확인한 값 (2026-10-27, `Shen-Lab/GraphCL` transferLearning_MoleculeNet_PPI/chem)**:
  온도 `T = 0.1`, 증강 비율 0.2 (`drop_num = int(node_num * aug_ratio)`, maskN도 같은 개수),
  projection `Linear(300,300) → ReLU → Linear(300,300)`, 풀링 `global_mean_pool`, 배치 256, 100에폭, lr 0.001.
  손실 `loss_cl`: 뷰1의 i와 뷰2의 i가 양성, **뷰2의 나머지만 음성**이고 분모에서 양성을 뺀다 (같은 뷰 음성·대칭항 없음). 그대로 구현했다.
  maskN은 가린 원자 피처를 **그 분자의 평균 원자 피처**로 바꾼다 → 그대로 따른다
- GraphCL과 다른 점: ① 증강 조합. GraphCL 화학 실험은 dropN·subgraph 중 무작위였지만 여기서는 뷰1 maskN, 뷰2 dropN으로 고정한다
  (원자 삭제를 넣어 마스킹 과제와 다르게 하려는 설계 의도, P3 권장 이유). ② 백본이 GIN이 아니라 D-MPNN.
  ③ 사전학습 풀링은 평균이지만 미세조정은 readout {mean, norm}을 탐색한다 (C·D 공통 탐색 공간 유지)
- 마스킹 과제(Hu et al.)는 분자마다 `int(n·0.15 + 1)`개 원자 피처를 0으로 바꾸고, 선형 헤드로 원자 종류 38칸을 맞힌다

권장 이유: 01 §3.5가 정한 두 과제이고, Sun et al. 2022가 평가한 방법(AttrMasking, GraphCL)과 같은 계열이라 정성 비교가 된다. 대조학습 증강에 원자 삭제를 넣어야 두 과제가 실제로 달라진다.

### 결정 P4. 백본 크기와 D의 탐색 공간 (가장 중요)

사전학습한 인코더는 `d_h`·`depth`가 고정이다. 반면 C v2는 `d_h`·`depth`까지 탐색했다. 그대로 비교하면 "사전학습 효과"와 "구조 탐색을 못 한 효과"가 섞인다.

| 후보 | 장점 | 단점 | 추가 그리드 |
|---|---|---|---|
| **① 크기 고정 + 대조군 C_fixed (권장)**: 인코더 1개 크기로 사전학습, D는 나머지 HP(dropout·lr·FFN·batch·readout)만 탐색. 같은 크기·같은 공간을 처음부터 학습하는 C_fixed를 추가 | D − C_fixed = 순수한 사전학습 효과, D − C v2 = 실용 비교. 둘을 분리해 보고 | C_fixed 그리드 1개 추가 | +7.8h |
| ② 크기 여러 개(예: 2×2)를 사전학습해 D가 그중에서 고름 | C v2와 탐색 공간이 비슷 | 사전학습 4배(방법당 4개), 시간 큰 폭 증가 | 사전학습 +25~30h |
| ③ 크기 고정, C v2와만 비교 | 가장 쌈 | D가 지면 "사전학습이 효과 없다"인지 "구조 탐색을 못 해서"인지 구분 불가 | 0 |

**고정 크기 후보**

| 후보 | 근거 | 비고 |
|---|---|---|
| **d_h 300, depth 3 (권장)** | chemprop 기본값. 우리 결과를 보기 전부터 정해진 외부 값 | AqSolDB 전체 예산에서 chemprop 기본값이 C v2와 같았다 (−0.001) |
| d_h ~250, depth 4 | C v2가 valid로 고른 값의 중앙값 (AqSolDB 194~273, Tox21 198~250, depth 3.5~4.5) | valid만 썼지만 우리 결과에 맞춘 값 |
| d_h 300, depth 5 | Hu et al. 2020 GIN 사전학습 설정과 같은 층 수 | 백본이 달라 층 수 대응이 정확하지 않음 |

권장 이유: ①은 비용 +7.8시간으로 해석이 갈리는 지점을 막는다. NeurIPS 2022의 지적("HP가 사전학습 과제보다 영향이 크다", H4)을 바로 이 대조군으로 검증할 수 있다. 크기는 외부 기본값을 써야 우리 결과에 맞춘 선택이 들어가지 않는다.

### 결정 P5. 사전학습 장치

| 후보 | 사전학습 시간 (2종, 100에폭) | 재현성 |
|---|---:|---|
| **① CPU 8스레드 + 결정론 모드 (권장)** | 약 7.3h (+여유 → 8~10h) | 처음부터 다시 돌려도 같은 가중치 (스레드 8 고정) |
| ② MPS | 약 4.5h (+여유 → 5~6h) | 실행마다 다른 가중치 (G3 실측). 가중치 파일을 커밋하면 이후 단계는 재현됨 |

초안 권장 이유: 차이가 약 3~4시간이고 밤새 돌리면 일정에 영향이 거의 없다. G3(재현 가능성 우선)과 같은 원칙을 지킨다.
어느 쪽이든 가중치 파일(약 1MB)과 SHA-256을 커밋한다.

**확정: ② MPS (§2.2 T2)**. 10/29 기한 때문에 속도를 우선했다. 사전학습은 1회만 하고(P6) 가중치를 SHA-256과 함께 커밋하므로,
재현되지 않는 부분은 "사전학습을 처음부터 다시 돌리는 경우"로 한정된다. 미세조정 그리드는 그 가중치로 CPU 결정론 실행이라 재현된다.

### 결정 P7. 분할 범위 (H3)

H3("교차점이 random보다 scaffold에서 오른쪽")은 random 분할의 GNN 결과가 있어야 검정할 수 있다. 지금 GNN은 scaffold_random만 돌렸다.

| 후보 | 추가 시간 | 비고 |
|---|---:|---|
| **① scaffold_random만 먼저, H3 범위는 D 결과를 본 뒤 결정 (권장)** | 0 | D가 어느 예산에서도 이득이 없으면 교차점 자체가 없어 H3는 의미가 없다 |
| ② 지금 random 분할도 추가 (C v2 + D 2종 + C_fixed, 2개 데이터셋) | +31h | H3를 처음부터 검정 |
| ③ random 분할은 C v2와 D 중 나은 1종만 | +15.6h | ②의 절반 |

초안 권장 이유: H3의 전제(교차점 존재, H2)가 성립하는지 모르는 상태에서 31시간을 쓰지 않는다.

**확정: D 결과를 보기 전에 범위를 고정한다 (§2.2 U1)**. 10/29 기한 안에 H3를 하려면 결과를 기다릴 수 없고,
결과를 보기 전에 정하는 편이 "결과를 보고 범위를 정했다"는 문제도 없앤다.

### 2.2 일정·범위 결정 (2026-10-27 확정, 기한 10/29)

#### T1. 탐색 횟수: 예산 1,000개 이하 20회, 3,000개·전체는 10회

| 후보 | D 관련 그리드 3개 | 비고 |
|---|---:|---|
| 전 예산 20회 | 24~28h | 기존 C·B와 같은 조건 |
| **예산 ≤1,000은 20회, ≥3,000은 10회 (채택)** | 15~18h | |
| 전 예산 10회 | 12.5~14.5h | |

- 근거 ① 비용: 그리드 시간의 77%(AqSolDB)·84%(Tox21)가 3,000개·전체 예산에서 나온다 (C 그리드 실측 조합당 시간)
- 근거 ② valid만으로 본 탐색 효과: C v2에서 20회가 10회보다 낫게 고른 valid 점수 차이(시드 중앙값)는 AqSolDB RMSE 0.0002~0.0065,
  Tox21 AUPRC 0~0.0044로 **모든 예산에서 작다**. 30~60% 조합은 10회와 20회가 같은 HP를 골랐다.
  즉 valid 기준으로는 큰 예산만 특별히 덜 민감하지 않다. 큰 예산만 줄인 이유는 비용이다
- **공개: test도 봤다.** 결정 과정에서 C v2 − B의 test 결과를 10회·20회로 비교했다. 3,000·전체는 두 데이터셋 모두 결론이 같았고,
  작은 예산(AqSolDB 100개 p 0.098 → 0.020, Tox21 1,000개 p 0.21 → 0.029)은 달랐다. 작은 예산을 20회로 남긴 데에는 이 test 비교도 영향을 줬다.
  D의 test 결과와는 무관하다 (D는 아직 학습 전)
- 적용: D 비교의 모든 모델(B, C v2, C_fixed, D 2종)을 예산마다 같은 체크포인트(`hp_n_trials`)로 비교한다.
  B·C v2는 이미 5/10/20 체크포인트를 기록해 다시 돌리지 않는다. 이전 보고서(C v2 − B, 20회 기준) 값은 바꾸지 않고, D 보고서에 두 기준을 함께 적는다
- 구현: `scripts/run_parallel.py --n-trials 20 --trials-for 3000=10 full=10`. 같은 시드면 앞 k회 후보열이 같아 체크포인트 값과 일치한다

#### T2. 사전학습 장치: MPS (P5 변경, 위 참고)

#### T3. 개발 범위: `packed.py`(float16 연결 배열) 제외

그래프 25만 개를 MolGraph 목록으로 올려도 1.65GB라(§1.3) 압축 저장이 필요 없다. 사전학습 코드를 먼저 만들고 실행기 통합은 그동안 진행한다.

#### T4. C_fixed 대조군 유지 (P4 그대로)

T1 덕분에 비용이 7.8h → 약 5h로 줄었다. D − C_fixed가 이 연구에서 순수한 사전학습 효과를 분리하는 유일한 비교다.

#### U1. H3 범위: random 분할, C v2와 "더 나은 D" 1개, 데이터셋 2개

| 후보 | CPU 시간 | |
|---|---:|---|
| 모델 4개 × random·scaffold × 2 | 약 60h | 기한 안 불가 |
| C v2 + D 1개 × random·scaffold × 2 | 19h | 여유 3~5h |
| **C v2 + D 1개 × random × 2 (채택)** | 9.6h | |
| 위와 같되 AqSolDB만 | 5.6h | |

- B의 random 분할 결과는 이미 있다 (5/10/20 체크포인트). 결정론적 scaffold 분할의 GNN 결과는 만들지 않는다 (B·A 결과만 있음)
- **"더 나은 D" 선택 규칙 (test를 쓰지 않는다)**: 데이터셋마다 scaffold_random 주 그리드에서, 예산별 체크포인트(T1)의 `hp_valid_score`를
  (시드, 예산) 쌍으로 D_mask와 D_contrast 사이에서 비교한다. 예산별로 시드 평균 차이를 구하고 예산들의 평균을 낸다
  (회귀는 RMSE라 작을수록, 분류는 AUPRC라 클수록 좋은 쪽). 이 평균이 나은 방법을 고른다. 정확히 같으면 D_mask
- 판정은 §4 H2와 같은 규칙을 random 분할에도 적용하고, 교차점이 분할에 따라 이동하는지를 기술한다 (검정하지 않음)

#### U2. 불확실성 비교 (01 §6 10주차): AqSolDB, C v2와 "더 나은 D", 방법 3가지

- 분할 scaffold_random, 시드 10개, 예산 5개. 각 조합에서 주 그리드가 valid로 고른 HP(T1 체크포인트)를 그대로 쓴다 (새 탐색 없음)
- **deep ensemble**: 같은 HP로 시드 5개(`subsample_seed + 10000·j`, j=0~4. j=0은 주 그리드 모델과 같다)를 학습해 평균·표준편차
- **MC dropout**: j=0 모델을 dropout 켠 채 30회 예측. 고른 HP의 dropout이 0이면 분산이 0이 되므로 그 비율을 함께 보고한다 (HP는 바꾸지 않는다)
- **split conformal**: valid 절대 잔차의 분위수로 90% 구간 (j=0 모델)
- 지표: 90% 구간 포함률, 평균 구간 폭, ensemble·MC는 표준편차와 |오차|의 Spearman 상관. 기술 통계만 낸다 (검정 없음)
- Tox21 분류와 B(LightGBM)의 불확실성은 하지 않는다

#### U3. 데모 앱: 최소 Streamlit

SMILES 입력 → B와 "더 나은 D"(AqSolDB, scaffold_random 시드 0, 전체 예산에서 valid로 고른 HP로 학습한 모델)의 logS 예측.
학습 분자와의 최근접 ECFP4 Tanimoto가 0.4 미만이면 "적용 범위 밖" 경고. 연구 결과가 아니라 시연용이며, 의사결정에 쓰지 말라고 표시한다.

#### 라벨 신뢰도 층화 평가 (01 §8)

AqSolDB test를 Group(G1 단일 출처 vs G2~G5 복수 출처)으로 나눠 B, C v2, "더 나은 D"의 예산별 RMSE를 낸다.
B는 분자별 예측이 시드 6·9만 저장돼 있어 scaffold_random 주 그리드를 `--save-preds`로 다시 실행한다 (결정론 → 저장된 지표와 같아야 하며, 다르면 중단하고 원인부터 찾는다).

## 4. 판정 규칙 (결과를 보기 전에 고정)

- 주 지표: AqSolDB RMSE, Tox21 AUPRC. 분할 scaffold_random, 시드 10개, 탐색 횟수는 예산 ≤1,000 20회, ≥3,000 10회 (T1, 모든 모델 같은 체크포인트)
- 비교 (각각 시드 쌍 Wilcoxon, 비교별 예산 간 Holm):
  1. **D − C_fixed** (사전학습 효과): 방법 2종 각각
  2. **D − C v2** (구조 탐색까지 한 C 대비)
  3. **D − B** (H2 교차점)
- H1(단조 감소): D − C_fixed 중앙값을 예산 순서로 나열해 단조성을 기술한다. 예산이 4~5개뿐이라 검정하지 않는다
- H2(교차점): D − B가 D 우세로 Holm 유의한 가장 큰 예산과, B 우세로 유의한 가장 작은 예산을 적는다. 둘 다 없으면 "교차점 없음"
- H4: D − C_fixed와 D − C v2의 차이(구조 탐색 효과)를 함께 보고, 문헌 보고 이득과 비교한다
- 사전학습 방법 2종 중 "더 나은 쪽"을 test로 고르지 않는다. 둘 다 보고한다. H3·불확실성·앱에 쓸 D 1개는 §2.2 U1의 valid 규칙으로만 고른다
- 보조: 3,000·전체 예산의 B·C v2는 20회 값도 함께 적는다 (T1 민감도)
- 실행 시간 표는 다른 앱의 CPU 경합 구간 조합을 뺀다 (`analyze_gnn.py --runtime-exclude`). 결정론 실행이라 성능 값에는 영향이 없다

|---|---|---|---|
