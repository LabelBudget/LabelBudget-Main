## 30초 요약

**무엇을 하는가**
자기지도 사전학습이 분자 물성 예측에 실제로 도움이 되는지, **라벨 수를 바꿔가며** 측정해 경계를 찾는다.

**왜 유효한가**
문헌 결론이 갈려 있다. Nature Communications(2023)는 서술자+GBM이 대부분 이긴다고 했고, NeurIPS(2022)는 자기지도 사전학습에 "통계적으로 유의한 우위가 없다"고 했다. 아직 닫히지 않은 질문이다.

**비교군 4종**

| ID | 모델 |
|---|---|
| A | ECFP4 + LightGBM |
| B | RDKit 2D 서술자 + LightGBM |
| C | GNN 처음부터 학습 |
| D | GNN + 자기지도 사전학습 |

**핵심 축**
라벨 수 `100 → 300 → 1,000 → 3,000 → 전체` (테스트셋 고정)

**최종 산출물**
B와 D의 성능 곡선이 교차하는 지점. 그 교차점이 분할 전략에 따라 이동하는지.

## 절대 놓치면 안 되는 4가지

### 1. 용해도 과제에서 염을 제거하지 말 것
짝이온이 용해도를 결정한다. 염을 벗기면 화학적으로 다른 물질이 하나로 병합되어 라벨이 최대 9.48 logS까지 충돌한다. 실측 근거는 `03` §4.

### 2. `scaffold` 분할은 결정론적이다
시드를 10개 돌려도 분산이 0이다. 시드 분산 측정은 반드시 `scaffold_random`으로.

### 3. 모든 모델에 동일한 하이퍼파라미터 탐색 예산을 줄 것
NeurIPS(2022)가 "하이퍼파라미터가 사전학습 과제보다 성능에 더 큰 영향을 준다"고 지적한 지점이다. 통제하지 않으면 실험 전체가 무의미해진다.

### 4. 분류 과제는 `SR-ARE`를 쓸 것
Tox21의 기본 과제 `NR-AR`은 양성률 4.25%다. 라벨 예산 100에서 양성이 **4개**뿐이라 실험이 성립하지 않는다. 근거와 대안은 `02` §1.4.

## 기록 원칙

- **음성 결과도 커밋한다.** 사전학습이 효과 없다는 결과는 문헌과 일치하는 유효한 발견이다
- 실험 설정은 `configs/*.yaml`로 외부화하고 결과 파일에 설정 해시를 남긴다
- `reproduce.sh` 하나로 전체 재현이 되어야 한다
- 노트북은 탐색용으로만. 결과를 만드는 코드는 `src/`에 둔다
