1. 메시지 패싱을 **라이브러리 상속 없이** 직접 구현한다 (01 §7-1)

## 1. 결정 사항

### 결정 G1. 백본: D-MPNN vs GIN

C와 D는 백본이 같아야 하므로(01 §3.1), 사전학습(6~7주차)까지 이 선택을 따른다.

| | **D-MPNN** (Chemprop) | GIN (Hu et al. 2020 사전학습 계열) |
|---|---|---|
| 메시지 단위 | 방향 있는 결합 (역방향 메시지 제외) | 원자 |
| 지도학습 성능 (문헌) | 분자 물성 예측에서 널리 쓰이는 강한 베이스라인 (Chemprop) | 데이터셋별로 다름. D-MPNN과의 직접 비교 근거는 **확인 필요** |
| 사전학습 문헌과의 호환 | 마스킹·대조학습 모두 적용 가능하나 사례가 적음 | Hu et al. 2020, GraphCL, Sun et al. 2022가 주로 사용 |
| 공개 사전학습 가중치 활용 | 불가 | 가능 (단, 우리는 직접 사전학습하므로 필수 아님) |
| 등가성 비교 대상 | chemprop v2 `BondMessagePassing` (공식 구현) | PyG `GINConv`/`GINEConv` |
| 구현 난이도 | 높음 (역방향 결합 인덱스, 결합→원자 집계) | 낮음 |
| 01 기획서와의 일치 | §7 "D-MPNN 직접 구현 + Chemprop 재현"과 일치 | 기획서 수정 필요 |

**권장: D-MPNN**
- 01 기획서의 구현력 증명 장치(§7)가 D-MPNN 기준으로 설계돼 있다
- "공식 Chemprop과 수치가 일치한다"는 증거는 "PyG 레이어와 일치한다"보다 강하다
- 사전학습 과제(마스킹·대조학습)는 백본과 무관하게 적용된다
- 약점: 사전학습 문헌(GIN 위주)과 직접 수치 비교는 어렵다 → 리포트에 명시. Sun et al. 2022의 결론과는 정성적으로 비교한다

### 결정 G2. 등가성 테스트의 비교 대상

| | (a) chemprop v2 공식 구현 | (b) 직접 짠 PyG `MessagePassing` 버전 | **(c) 둘 다** |
|---|---|---|---|
| 증명하는 것 | 공식 D-MPNN과 같은 계산 | 두 구현 방식(scatter vs PyG)이 같은 계산 | 둘 다 |
| 증거 강도 | 강함 | 약함 (내 코드끼리 비교) | 강함 |
| 의존성 | chemprop + lightning 설치 (테스트 전용) | PyG만 | 둘 다 |
| 01 기획서 문구 ("PyG 구현과 비교") | 불일치 | 일치 | 일치 |
| 추가 공수 | 가중치 복사 매핑 작성 | PyG 버전 약 50줄 | 둘 다 |

**권장: (c)**
- PyG에는 D-MPNN 레이어가 없어서 (b)만으로는 "내 코드끼리 일치"에 그친다
- (a)가 실질적인 증거이고, (b)는 기획서 약속을 지키면서 "scatter 직접 구현 = 프레임워크 추상화"를 보여준다
- chemprop은 `[project.optional-dependencies] equiv`로 분리해 본 실험 환경 의존성을 늘리지 않는다

### 결정 G3. 실행 장치: CPU vs MPS

| | CPU | MPS (Apple GPU) | **용도별 분리** |
|---|---|---|---|
| float64 | 지원 | **미지원** | 등가성 테스트는 CPU float64 |
| 결정성 | 높음 | scatter 계열 연산에서 비결정 가능 | 실험은 실측 후 결정 |
| 속도 (작은 그래프 배치) | 측정 필요 | 측정 필요 | §4 벤치마크로 결정 |
| LightGBM 그리드와 동시 실행 | CPU 경합 | 경합 적음 | — |

**권장: 용도별 분리** — 등가성 테스트는 CPU float64로 고정, 학습 장치는 §4 벤치마크(CPU vs MPS, 같은 시드 2회 재현성 포함)로 정한다. 지금 한쪽으로 정할 근거(실측)가 없다.

### 결정 G4. Chemprop 재현의 기준

| | (a) 논문 보고 수치 재현 | **(b) 공식 chemprop을 우리 분할에서 실행해 비교** |
|---|---|---|
| 비교 조건 | 논문의 분할·전처리를 그대로 구해야 함 (구하기 어려울 수 있음) | 같은 데이터·같은 분할·같은 지표 |
| 차이가 날 때 원인 추적 | 어려움 (분할·전처리·버전이 섞임) | 쉬움 (구현 차이만 남음) |
| 문헌 신뢰도 신호 | 높음 | 중간 |

**권장: (b)를 주로, (a)는 공개 분할을 구할 수 있는 경우에만 보조로** — 01 §7-2의 목적("재현했고, 차이는 원인 X")은 원인 추적이 가능한 (b)에서 달성된다. 논문 수치는 이 문서에서 **확인 전까지 인용하지 않는다**.

### 결정 G5. GNN 그리드 범위 — **§4 벤치마크 후 결정** (후보만 기록)

베이스라인 그리드는 데이터셋당 450조합 × 탐색 20회다. GNN 1회 학습이 수 분이면 같은 규모는 감당할 수 없다.
후보: ① 전체 그리드 + `n_trials` 체크포인트 중 작은 값 · ② 예산 사다리 유지, 분할은 scaffold_random만 ·
③ 모든 모델의 `n_trials`를 함께 낮춤 · ④ 에폭 상한·조기 종료로 1회 비용 축소.
벤치마크 실측(1회 학습 시간 × 예산별)으로 비교표를 만든 뒤 결정한다.

### 2.1 그래프 피처

- chemprop v2 기본 원자·결합 피처 정의를 따른다 (재현 비교를 위해). 정의는 설치한 chemprop 소스에서 확인해 이 문서에 표로 기록한다
- 수소는 암시적 (원자 피처의 H 개수로 표현)
- 결합이 없는 그래프는 큐레이션에서 제거된다 (중원자 3개 미만은 `too_small`, 끊긴 조각은 `multi_component`). 그래도 0결합 입력에 대한 방어 테스트를 둔다

### 2.2 D-MPNN 계산 (직접 구현)

```
z_{v→w}   = W_i · [x_v ‖ e_vw]                    ← 활성화 전 값을 보관
h¹_{v→w}  = ReLU(z_{v→w})
m^{t+1}_{v→w} = Σ_{k∈N(v)\{w}} h^t_{k→v}       ← 들어오는 메시지 합 − 역방향 메시지
h^{t+1}_{v→w} = ReLU(z_{v→w} + W_h · m^{t+1}_{v→w})   ← 매 단계 z를 더한다 (chemprop v2와 동일, 설치 후 소스로 재확인)
m_v = Σ_{k∈N(v)} h^T_{k→v};  h_v = ReLU(W_o · [x_v ‖ m_v])
분자 표현 = 원자 h_v의 평균(또는 합) → FFN
```

- `index_add_`로 결합→원자 합을 구하고, 역방향 결합 인덱스 `rev`로 `a_msg[src] − h[rev]`를 계산
- PyG·torch_scatter 의존 없이 순수 torch로 작성

### 2.3 등가성 테스트 수락 기준

| 테스트 | 기준 |
|---|---|
| 직접 구현 vs PyG 버전 | 같은 가중치, float64, 무작위 분자 50개, 원자·분자 표현 max\|Δ\| < 1e-5 |
| 직접 구현 vs chemprop `BondMessagePassing` | 가중치 복사 후 동일 기준 |
| 역방향 메시지 제외 검증 | 2원자 분자에서 1스텝 후 메시지가 초기값과 같은지 (손 계산) |
| 배치 독립성 | 분자 1개씩 계산한 결과 = 배치 계산 결과 |

### 2.4 학습

- 손실: 회귀 MSE, 분류 BCE. valid 지표 기준 조기 종료 (patience, 최대 에폭은 탐색 공간/벤치마크로 결정)
- 탐색 공간(초안): hidden ∈ {150…600}, depth ∈ {2…6}, dropout ∈ [0, 0.4], lr log [1e-4, 3e-3], batch ∈ {32, 64}
- `random_search`와 같은 체크포인트 인터페이스 (`hp_n_trials` 5/10/20) — 베이스라인과 동일 예산 원칙
